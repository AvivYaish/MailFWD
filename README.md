# MailFWD
- Forward unread Outlook mail and mark it read, while retaining original reply-to and cc address.
- Can also optionally pass a starting time to forward all messages received later, even if already read.
- Only requires logging-in to the `from` account, and supports securely storing that account's password locally.
- Works with any Outlook account that supports Thunderbird!

Usage: `python MailFWD.py --from from@address.com --to to@address.com`
